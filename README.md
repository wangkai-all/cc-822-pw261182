# 降水预报偏差校正应用

对零膨胀（含大量零值）的日降水预报做统计后处理的独立应用。它把问题拆成两个统计阶段
分别校正，并显式处理零值质量、超训练范围尾部、季节差异与时间隔离，所有标定均版本化、
可复现。**纯本地演示，不连接任何气象业务平台。**

## 它解决什么问题

直接把预报数值映射到历史观测（普通分位映射）会把未来气候态也拉回历史，**抹掉真实的变化
趋势**。本应用同时提供两种量级映射并对比其后果：

| 维度 | 普通分位映射 QM | 保持变化信号 QDM |
|---|---|---|
| 公式 | `x_c = Q_obs(F_fut(x))` | `x_c = Q_obs(τ) + (x − Q_hind(τ))`，`τ=F_fut(x)` |
| 边际分布 | 贴合历史观测 | 贴合历史观测 |
| 未来趋势 | 抹除 | 保留（含极端尾部的变化量 Δ） |

发生阶段同样有两族：`plain` 把湿日频率压回历史观测频率；`trend` 在 log-odds 上保留未来
频率的相对变化。两族 × 两种实现（确定性阈值 / 随机化分位）。

## 两阶段校正链

1. **发生与否（零值质量，`occurrence.py`）**
   - 确定性：按目标湿日频率取秩阈值，前 k 大为湿，其余严格置零，无任何随机。
   - 随机化分位（Dunn–Smyth）：在经验 CDF 台阶 `[F(x−), F(x)]` 内做均匀抽样。
     **种子、完整位发生器状态、每次均匀抽样都随标定落盘**，可逐位复现；
     绝不通过无状态地随机删点来改变湿日频率。
2. **湿日量级（`amount.py`）**：仅对发生阶段判湿的日子做 QM 或 QDM；干日不进入量级映射。
3. **尾部（`distributions.py`）**：阈值以上拟合广义帕累托（GPD，失败回退指数分布）。
   - `extrapolate`：超 hindcast 训练最大值的点走观测尾部外推并**打标**，QDM 保留 Δ；
   - `clip`：最终校正值封顶在观测最大值。
4. **季节（`seasons.py`）**：分季（DJF/MAM/JJA/SON）各自拟合、按原行序重组；也可全年不分季。

## 时间隔离（`splits.py` + `pipeline.py`）

训练、方法选择、评估使用**三个互不重叠、按年连续、不洗牌**的块，逐年向前滚动：

```
|← 训练(拟合分布) →|← 选择(验证集挑方法) →|← 评估(仅报告) →|
```

- 测试块从不参与拟合或方法选择；方法选择只看验证块上的 Brier + 归一化湿日量 MAE 复合分。
- 合成数据含**已知偏差**（毛毛雨概率 0.18、强度倍率 1.25）与**已知趋势**
  （湿日 log-odds +0.03/年、强度 log +0.02/年），用于核对分位、湿日与时间隔离。
- “未来真值”仅用于页面核对，从不进入任何拟合。

## 标定版本化与观测修订（`storage.py`）

- 每次标定生成不可变 `calibration_id` 与指纹，pickle 引擎对象 + JSON 元数据落盘。
- 校正产品记录标定 id、标定指纹、观测修订 id 与观测数组 SHA-256 指纹。
- 观测被修订后，**旧产品仍绑定原标定分布**，界面与 API 将其标记为 `stale` 而不会用新分布
  静默重算；需要时再用新观测生成新标定。

## 目录结构

```
app/
  engine/        # 纯统计引擎（无 Web 依赖），可独立测试与复用
    distributions.py  经验分布(零质量+Weibull 绘点) 与 GPD 尾部
    occurrence.py     阶段一：发生校正（确定性/随机化，RNG 持久化）
    amount.py         阶段二：QM / QDM 与尾部策略
    seasons.py        季节分层
    splits.py         连续年份滚动隔离
    metrics.py        湿日比例/分位变化/极端尾部/选择损失
    synthetic.py      已知偏差+已知趋势的合成数据
    pipeline.py       编排、CV 选择、版本化标定、单条映射来由
    storage.py        导入校验、标定存储、产品导出、修订绑定
  web/           # Flask 服务 + 自包含 SVG 前端（无 CDN，离线可用）
  cli.py         # 命令行入口
tests/           # 27 项 pytest（引擎 + 存储 + Web 全链路）
data/imports     # 示例导入 CSV；data/runtime 为运行时产物（已 gitignore）
```

## 快速开始

```bash
./setup.sh                                   # 建虚拟环境并装依赖
./run.sh                                     # http://127.0.0.1:5050
.venv/bin/pytest                             # 运行全部测试

# 命令行：生成虚构示例 -> 交叉验证 -> 标定 -> 校正 -> 导出
.venv/bin/python -m app.cli generate --out data/imports
.venv/bin/python -m app.cli run \
  --history data/imports/history.csv \
  --future  data/imports/future.csv \
  --out data/runtime/product.csv
```

## 页面能力

- 选择季节模式与查看季节、调整尾部处理（GPD 外推 / 截断）与尾部阈值、发生实现、随机种子。
- 一键载入合成数据，或上传两个 CSV：
  - 历史：`date,obs,hindcast`；待校正：`date,forecast`（降水不可为负、日期唯一）。
- 湿日比例卡片、分位变化曲线+数值表、极端尾部与超训练范围计数、未来时间序列（带悬停十字线）。
- 连续年份 CV 的分段条与逐季选择依据；单条预报的两阶段映射来由（CDF、均匀抽样、τ、
  Q_obs、Q_hind、保留 Δ、尾部标志、修订绑定状态）。
- 标定版本列表与修订绑定状态；导出含原值/校正值/标定与观测指纹的 CSV。
- 亮/暗主题；图表配色经色盲与对比校验，数值均提供表格视图。

## 安全说明

导入文件视为不可信数据：严格列名/类型/取值校验，在独立临时目录读取，不依赖文件所在目录
执行代码。引擎本身不发起任何网络请求。
